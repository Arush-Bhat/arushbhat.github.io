# arushpbhat.github.io

A minimal, dark, geometric personal website built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — page content and structure
- `style.css` — colors, layout, responsive design, typography
- `script.js` — mobile navigation, active section highlighting, current year
- `assets/cv.pdf` — add your CV PDF here (create the `assets` folder)

## Before publishing

Search `index.html` for these placeholders and replace them:

- `YOUR_EMAIL@example.com` — your public contact email
- `Add your current degree or role`
- `Add your city / country, if desired`
- `Your project title` and the example project descriptions
- `Add another profile`
- The interest-card descriptions
- Any links with `href="#"`

The CV link expects a PDF at `assets/cv.pdf`. If you do not want to publish a CV yet, remove the CV link or leave it unpublished until the file is added.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **public** repository named exactly `arushpbhat.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root. Upload the `assets` folder if you have added your CV.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for the Pages deployment to finish. Visit `https://arushpbhat.github.io/`.

## Editing later

Edit `index.html` for wording and links. Edit `style.css` for the visual design. Edit `script.js` only if you want to change the small navigation behaviours.

## Notes

- Lexend is loaded from Google Fonts; a system sans-serif fallback is defined if the font service is unavailable.
- This is a static site. It does not require a build step, package manager, or JavaScript framework.
- Avoid publishing personal information you do not want publicly indexed.
